Privacy Policy: Clay Personal AI

Effective November 20, 2026

Clay Personal AI is a single-user tool. Its only user is the owner of the Google account it connects to.

What it accesses

With the owner's permission, it reads and organizes the owner's own Gmail messages, Google Calendar events and tasks, and Google Drive files.

How data is used and stored

Data is used only to carry out tasks the owner requests. Access tokens and any retrieved data are kept on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
